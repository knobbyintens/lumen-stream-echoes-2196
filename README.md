# Lumen Stream licence echoes (Stream Wave 2)

Community copies, archival snapshots, prior audit runs and a public working copy of
the Lumen Stream release desk, collected here for reference. Datasets covered:
Lumen-Stream-Code, Lumen-Stream-Syn and Lumen-Stream-Mix.

These artefacts were produced independently and their licence statements may not
reflect the current authoritative records for the exact release artefacts.

Directories: `mirror/`, `datasync/`, `syn-clone/`, `runs/`, `benchmark/`,
`desk-public/`, `discussions/`.
